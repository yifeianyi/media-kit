# Spec Delta

## Purpose

将完整媒体托管能力作为独立、可安装且可修改的 Python 发行包交付，使不同技术栈的项目无需参考仓库或 Web 框架即可接入，并能够在干净环境验证安装、命令行、类型信息及源码重新构建。

## ADDED Requirements

### Requirement: 运行时独立于 Web 框架与参考项目

发行包 SHALL 支持 Python 3.11 及声明支持的更新版本，运行时仅依赖已声明的通用图片处理依赖与标准库能力。导入和执行核心功能 MUST 不要求安装 FastAPI、Flask、Django，不导入参考项目的 `app.*`、业务表或鉴权代码；普通模块导入不得创建文件、数据库或后台进程。

#### Scenario: 在纯 Python 环境使用
- **WHEN** 干净 Python 环境仅安装发行包及其声明的运行时依赖
- **THEN** 调用方可以初始化存储、保存、转换、查询、替换和删除图片，无需安装 Web 框架

### Requirement: 公开 Python 接口覆盖完整使用流程

发行包 SHALL 提供有文档的稳定入口，覆盖配置、显式初始化与打开、保存、分页查询、批量解析、带版本替换、删除、任务查询及重试、文件核对、恢复和独立转换。结果 MUST 明确表达资产身份、版本、可用媒体和处理状态，调用方不必读取内部数据库完成正常流程。

#### Scenario: 完整生命周期仅使用公开接口
- **WHEN** 接入方按文档完成图片创建、查询、转换、替换及删除
- **THEN** 所有操作均可通过公开入口及返回结果完成，不需导入内部模块或手写包内 SQL

### Requirement: 公开类型与错误契约可使用

发行包 SHALL 为公开配置、输入、返回结果和错误提供类型信息，并使类型检查工具能够识别安装包为带类型包。错误必须可区分输入错误、冲突、不存在、兼容性错误及处理失败，不要求调用方解析自然语言错误字符串作控制流程。

#### Scenario: 类型检查已安装包的接入代码
- **WHEN** 调用方对使用公开接口的有效示例执行支持的类型检查
- **THEN** 类型信息可从已安装发行包读取，并能识别示例输入输出及错误类型

### Requirement: CLI 支持独立管理与明确退出结果

发行包 SHALL 提供随安装可用的命令入口，覆盖存储初始化、worker 单次及持续运行、任务查询与重试、文件核对、恢复及离线文档定位。命令必须提供帮助信息，成功与失败返回明确退出状态，危险变更不得通过只读查询命令隐式执行。

#### Scenario: 查询命令失败
- **WHEN** 调用方使用不存在或不兼容的存储配置运行查询命令
- **THEN** 命令返回非成功退出状态和可识别原因，不创建或修改该存储

#### Scenario: 查看安装后的命令帮助
- **WHEN** 用户在仅安装发行包的环境中执行命令帮助
- **THEN** 系统列出可用操作及必要参数，不依赖源码仓库路径

### Requirement: 标准发行物包含运行所需资源

项目 SHALL 能构建标准 wheel 和 sdist，准确声明 Python 版本、运行时依赖、包版本及命令入口。两个发行物 MUST 包含公开类型信息、离线文档及运行所需资源；安装后不得依赖源码工作目录或运行时网络下载缺失资源。

#### Scenario: 从 wheel 安装并离开仓库运行
- **WHEN** 在干净环境安装 wheel 后从仓库外目录执行文档中的接入流程
- **THEN** 包、命令、类型信息和所需资源均可使用，不回读源码仓库

#### Scenario: 从 sdist 构建安装
- **WHEN** 在干净环境从 sdist 构建并安装发行包
- **THEN** 安装结果具备与 wheel 相同的公开功能和必需离线资源

### Requirement: 源码支持修改测试及重新打包

项目 SHALL 交付完整 Python 源码、测试、示例和构建配置，使使用者能够获取源码、以开发模式安装、修改处理行为、执行检查并生成自己的发行物。不得将关键运行逻辑仅以不可修改资源交付，文档必须说明 fork 后版本与命名的调整方式。

#### Scenario: 修改源码后重新构建
- **WHEN** 使用者按二次开发指南修改一个受支持的处理行为并更新相关检查
- **THEN** 能在本地构建并安装修改后的发行物，运行结果体现该修改

### Requirement: 发行版本与存储兼容信息可识别

发行包 SHALL 暴露其发行版本，并声明相应的配置、磁盘格式及 schema 兼容范围。版本说明必须区分安装升级与存储升级，不能把依赖安装成功等同于所有旧存储可被无条件写入。

#### Scenario: 诊断存储兼容问题
- **WHEN** 接入方获取包版本与存储格式信息
- **THEN** 可以依据随包说明判断兼容性和所需升级步骤，不必推测内部数据库结构

### Requirement: 许可与来源声明随源码及发行物交付

项目 SHALL 按 MIT 开源许可交付自身源码，并在源码及发行物中包含适用许可与必要来源署名。实际复用参考文件或其他来源材料前 MUST 核实权属与许可要求；不得把未经核实的来源声明为已获 MIT 授权。

#### Scenario: 检查安装包许可
- **WHEN** 使用者检查源码、wheel 或 sdist 中的许可资源
- **THEN** 能读取项目适用许可、版权信息及实际复用材料所需的来源声明
