# Spec Delta

## Purpose

为独立 Python 项目提供新媒体目录的完整托管契约，使接入方能够配置并理解原图、派生图和私有状态的位置，同时获得稳定的资产寻址、安全文件边界及与部署方式解耦的访问地址。

## ADDED Requirements

### Requirement: 显式初始化全新受管存储

系统 SHALL 区分初始化和打开已有存储。新建初始化只能使用不存在或符合空目录要求的位置，建立可识别的存储身份与格式版本；相同实例和配置的重复初始化必须幂等。系统 MUST 拒绝将含有未登记媒体的目录隐式接管为新存储。

#### Scenario: 初始化空目录
- **WHEN** 调用方显式初始化一个新目录并提供有效配置
- **THEN** 系统创建所需受管目录和私有状态，并允许通过相同存储身份重新打开

#### Scenario: 拒绝已有图片目录
- **WHEN** 调用方尝试初始化含有未登记图片的目录
- **THEN** 系统报告目录不为空且不登记、移动或删除这些文件

### Requirement: 存储布局固定且目录相互隔离

系统 SHALL 支持配置媒体根、原图目录、派生图目录和私有状态目录，并在初始化时记录布局。媒体根和私有状态目录 MUST 为显式绝对路径且互不嵌套；原图及派生图目录必须在媒体根内且互不重叠或包含。打开已有存储时 MUST 拒绝与已记录布局不一致的配置，不自动迁移文件。

#### Scenario: 使用自定义目录名
- **WHEN** 初始化时将原图和派生图配置为媒体根内独立相对目录，并将状态配置为媒体根外独立绝对目录
- **THEN** 后续写入仅使用已记录的对应目录，并可在重新打开后继续读取

#### Scenario: 拒绝变更既有布局
- **WHEN** 调用方使用不同原图目录配置打开同一个已有存储
- **THEN** 系统报告布局不一致且不新建替代目录或移动既有文件

### Requirement: 逻辑路径与物理文件地址分离

系统 SHALL 接受可选的规范相对逻辑 key；省略 key 时自动分配并返回唯一 key。物理原图 MUST 位于原图目录下按 asset_id、revision 和安全文件名分层的位置，派生图 MUST 位于派生图目录下按 asset_id、revision、配方指纹和 profile 分层的位置。业务 key 不得直接覆盖这些物理身份。

#### Scenario: 保存带业务逻辑路径的图片
- **WHEN** 调用方使用 key `articles/42/cover.jpg` 保存图片
- **THEN** 系统保留该逻辑 key，同时返回独立 asset_id 和受管原图地址，物理路径包含该资产及其版本

#### Scenario: 自动分配逻辑路径
- **WHEN** 调用方保存图片但没有提供 key
- **THEN** 系统分配唯一 key，并在保存结果和后续查询中一致返回它

### Requirement: 拒绝越界及歧义路径

系统 MUST 校验目录配置、逻辑 key、输入文件名和受管文件解析结果，拒绝绝对逻辑路径、路径穿越、空路径段、反斜杠、空字符及越出受管目录的符号链接。校验失败不得在受管边界外读写或删除文件。

#### Scenario: 拒绝路径穿越
- **WHEN** 调用方提供 `../outside.jpg`、绝对路径或含歧义路径段的 key
- **THEN** 系统返回路径错误且不创建资产、任务或目标文件

#### Scenario: 拒绝符号链接越界
- **WHEN** 受管文件的解析路径通过符号链接指向受管边界外
- **THEN** 系统拒绝该文件操作，并保留边界外文件不变

### Requirement: 访问地址由当前映射生成

系统 SHALL 将原图及派生图的 URL 前缀与磁盘布局分开配置，并按当前前缀和编码后的相对路径生成地址。前缀变化不得改变 asset_id、revision 或移动文件；未配置前缀时 SHALL 返回可用的受管路径信息和明确的无 URL 结果，不猜测网站路由。

#### Scenario: 调整静态访问前缀
- **WHEN** 同一存储的原图 URL 前缀由一个有效地址改为另一个地址
- **THEN** 后续解析使用新前缀，原图文件、资产身份和内容版本保持不变

#### Scenario: 私有状态不生成公开地址
- **WHEN** 调用方查询数据库、恢复日志或暂存文件的位置
- **THEN** 系统不会通过媒体 URL 映射为这些私有文件生成公开访问地址

### Requirement: 发布文件完整且私有状态不公开

系统 MUST 仅在文件完整安装后提供对应的已就绪媒体结果，不将半写入内容作为正式原图或派生图发布。暂存、安装备份、隔离文件和恢复日志 MUST 保持私有；与最终文件关联的安装暂存必须满足原子发布所需的同文件系统约束。

#### Scenario: 文件安装途中中断
- **WHEN** 进程在写入安装暂存时中断
- **THEN** 正式媒体地址不会指向部分写入的文件，重新打开存储后可识别未完成操作

### Requirement: 文件核对不隐式接管或清理

系统 SHALL 提供文件与元数据核对能力，报告登记文件缺失、内容不匹配及受管目录中的未知文件。默认核对 MUST 只读，不自动登记未知文件、不覆盖内容、不删除文件；修复已登记中断操作应通过明确恢复入口执行。

#### Scenario: 检出外部文件修改
- **WHEN** 调用方对存在缺失、被改写和未知文件的存储执行核对
- **THEN** 系统逐类报告差异，同时保持文件内容和资产记录不变

### Requirement: 不兼容存储版本明确拒绝

系统 SHALL 记录磁盘格式和元数据 schema 版本；遇到当前发行版不支持的较新版本时 MUST 拒绝写入并返回可识别的兼容性错误。版本迁移必须通过已声明且显式执行的升级路径，不得在普通读取中执行不可逆升级。

#### Scenario: 较旧程序打开较新存储
- **WHEN** 当前程序打开一个由较新且不兼容的版本建立的存储
- **THEN** 系统说明版本不兼容，并保持存储文件及元数据不变
