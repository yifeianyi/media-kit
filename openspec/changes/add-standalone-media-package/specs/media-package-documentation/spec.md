# Spec Delta

## Purpose

为人类开发者和编码 agent 提供随安装包交付的中文优先离线知识入口，使其不依赖原始讨论、外部网站或参考仓库，也能准确完成接入、日常运维、故障恢复、升级及源码二次开发。

## ADDED Requirements

### Requirement: 离线文档随所有发行形式交付

项目 SHALL 在源码、wheel 和 sdist 中包含完整的人类与 agent 文档，并提供安装后的文档定位或读取入口。核心接入与运维内容必须可以在断网且没有源码仓库的环境中读取；本地导航链接和文档资源不得指向仅存在于开发机器的路径。

#### Scenario: 离线读取 wheel 文档
- **WHEN** 用户在仅安装 wheel、没有源码目录且已断网的环境中打开文档入口
- **THEN** 可以读取接入、API、生命周期及运维说明，相关本地链接和资源可访问

### Requirement: 配置与目录文档明确托管边界

文档 SHALL 说明全新存储初始化、打开已有存储、root 内原图/派生目录与 root 外私有状态目录、固定布局限制、逻辑 key 与物理地址区别、URL 映射和静态服务器边界。必须明确不支持接管已有媒体目录，不将整个存储根或私有状态目录作为公开静态目录。

#### Scenario: 按文档配置自定义静态地址
- **WHEN** 接入方按文档配置自定义原图和派生图目录及 URL 前缀
- **THEN** 能得到正确媒体地址，并知道哪些目录必须保持私有、哪些配置不能在已有存储上直接修改

### Requirement: 公开 API 文档包含操作后置条件

文档 SHALL 覆盖全部公开 API 的输入、输出、错误、重试及操作成功后的文件与记录状态，解释 asset_id、key、revision、profile 指纹和任务状态。必须区分保存、替换、幂等重放、删除、重试与新配方请求，不能把语义留给调用方推测。

#### Scenario: 判断替换失败后的状态
- **WHEN** 开发者查阅版本冲突或输入校验失败的替换操作说明
- **THEN** 能确认当前原图与版本是否改变、错误如何识别以及何时可以安全重试

### Requirement: 完整纯 Python 示例可独立运行

项目 SHALL 提供不依赖 Web 框架的可运行示例，覆盖新目录初始化、保存、同步等待或 worker、批量解析、分页查询、带版本替换和删除，并提供独立文件转换示例。示例必须使用独立临时目录或显式路径，不依赖参考项目数据库、私有图片或网络服务。

#### Scenario: 在干净环境运行完整示例
- **WHEN** 用户按离线文档在干净环境执行所交付示例
- **THEN** 可以完成整个媒体生命周期并核对原图保留、派生生成和删除结果，无需额外业务项目

### Requirement: 集成文档解释业务事务和缓存限制

文档 MUST 解释包内媒体事务不与宿主业务数据库共同提交，提供媒体成功而业务保存失败、响应丢失后重试的接入处理示例。必须说明业务引用和授权由宿主管理，包不自动删除未关联资产，源站删除不等于撤回浏览器或 CDN 缓存。

#### Scenario: 宿主业务事务失败
- **WHEN** 开发者阅读保存媒体后宿主业务事务失败的接入示例
- **THEN** 能按示例查询已保存资产、选择继续关联或显式补偿删除，而不会误以为媒体已共同回滚

### Requirement: 运维与升级说明可执行

文档 SHALL 说明 worker 启停、单次处理、任务查询和重试、租约恢复、文件核对、删除未完成状态、私有清理、备份恢复及磁盘与 schema 升级。备份恢复必须解释如何获得同一一致时点的文件与元数据；升级必须说明兼容检查、停止写入要求和失败恢复边界。

#### Scenario: worker 中断后恢复
- **WHEN** 运维人员按文档处理一个租约到期的中断任务
- **THEN** 可以识别任务状态、重新启动处理并验证结果，而无需直接编辑包数据库

#### Scenario: 准备恢复备份
- **WHEN** 运维人员按文档执行存储备份与恢复
- **THEN** 能确定所需文件、数据库及操作状态的一致性条件，并知道不能将旧数据库无条件覆盖新增内容

### Requirement: agent 导航与源码修改指南完整

项目 SHALL 提供面向接入 agent 的导航入口及面向源码开发的 AGENTS 约定，列明模块职责、公开接口、关键不变量、相关文档、验证命令与支持范围。二次开发说明必须覆盖开发安装、修改转换规则及算法版本、更新测试和文档、fork 命名版本、构建发行物及来源署名核验。

#### Scenario: agent 调整缩略图行为
- **WHEN** 编码 agent 从交付的导航和源码开发约定开始查找修改缩略图规则的方法
- **THEN** 能定位处理模块、配方指纹约束、相关测试和构建步骤，不依赖聊天历史或参考项目规则

### Requirement: 文档与示例接受发行物验证

项目 MUST 将离线资源完整性、文档本地链接、公开接口示例和核心接入流程纳入可重复检查。检查必须至少针对已构建并安装的 wheel 与由 sdist 构建的安装结果，避免源码目录掩盖遗漏资源或导入问题。

#### Scenario: 发行物漏带文档资源
- **WHEN** 构建产物缺少必要离线文档、示例依赖资源或存在失效的本地导航
- **THEN** 相应发行检查失败并指出遗漏，不仅凭源码目录中存在文件而通过
